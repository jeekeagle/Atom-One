## 一、设计立意

Atom 方法体系的核心是**原子式智能体单元**——把智能体拆解到不可再分的最小单元，再看单元如何组合成系统。视觉表达直接从这条逻辑出发，借用原子物理学的三件套：

| 概念 | 视觉母题 |
|---|---|
| 不可再分的核 | 中心实心圆点 |
| 可组合的单元 | 等距、均质的圆点或方块 |
| 无限递归的内部结构 | 同形递减的嵌套圆环 |

**风格定位**：学术出版物的克制感。纯黑、无渐变、无阴影、无拟物光效——辨识度全部由几何关系建立，而不是装饰堆砌。所有图形使用 `currentColor` 着色，置于任意父容器即整体换色。

**核心约束**（贯穿全部方案）：核心元素 1–2 个；负空间 ≥ 40%；线宽 1.5–3；单一视觉焦点；元素间距 ≥ 8。

## 三、我的推荐

**唯一标识 → 07 字母骨架**
唯一同时满足三个条件的方案：识别度最高（32px 起清晰可辨）、具有 "Atom" 字面锚点、笔画少到不可能画错。适合做课程、论文体系、开源项目的署名标记。

**表达方法论本质 → 08 递归嵌套 / 12 分形分解**
08 三个同心正圆，嵌套关系直接对应"单元内部仍是单元"；12 则是把递归画成了树。两者最像学术徽章。

**favicon → 03 蜂巢 / 11 开窗 / 14 切分 / 15 对握**
四个在 16px 下形体完整。

**视觉张力最强 → 10 摩尔干涉**
干涉纹是全部 15 个里唯一"凭空生成"的图形，最有记忆点，但小尺寸失效，仅建议 ≥64px 使用。

### 工程约定

`variants.py` 是唯一数据源。SVG 生成、展示页、资产导出全部从它读取，**不存在手抄转录**。

```bash
python generate.py        # 生成 15 套 SVG + PNG
python build_showcase.py  # 重建 showcase.html
python export_assets.py   # 导出多尺寸/favicon/反白/单黑
```

新增方案只需在 `variants.py` 里加一个 `build()` 函数和一条 `VARIANTS` 记录，其余全自动。

## 六、使用规范

**颜色**：主色 `#1A1A1A`（墨黑）；强调色 `#8A4A3F`（锈红，仅用于页面元素强调，不进图形本体）。反白用 `#F2F0EC`。

**着色**：所有 SVG 用 `currentColor`，由父容器 `color` 属性控制：

```html
<div style="color: #1A1A1A"><img src="v8-recursive.svg"></div>
```

**安全边距**：应用图标由导出脚本自动裁切居中，图形占画布 80%。SVG 源文件保留 10–15 单位原始边距。

**最小使用尺寸**：03/05/07/08/09/11/14/15 ≥ 16px；02/06/13 ≥ 32px；01/04/10/12 ≥ 64px。
