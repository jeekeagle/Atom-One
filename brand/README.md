# Atom 标志 · 透明底资产包

从资料库页面「Atom · 联合锁定组合（图标 + 字标）」抽取的完整标志系统，导出为透明底文件。

## 内容

```
atom-logo-export/
├─ svg/      300 个矢量文件（.svg，自带透明底，无背景矩形）
└─ png/      500 个位图文件（.png，RGBA，透明底）
└─ manifest.json   每个文件的结构样式 / 配色 / 主色 / 强调色
```

## 文件命名

```
atom-icon-<结构>-<配色>[-1024|-256].png     纯图标（正方形画布）
atom-icon-reverse-<结构>-<配色>[-1024|-256].png   深底反白版
atom-lockup-<结构>-<配色>.png                横向锁定组合（图标 + Atom 字标 + METHOD SYSTEM 副标）
```

`svg/` 下同名 `.svg` 文件对应同一图形，去掉尺寸后缀即可。

## 结构样式（10 种）

| id | 名称 | 说明 |
|---|---|---|
| s1-nested | 标准嵌套 | 外轮廓与内轮廓错位 30°，原选定稿 |
| s2-solid-outer | 外实心中空 | 实心外壳镂空内核，识别度最高 |
| s3-solid-inner | 内实心 | 外描边内实心，块面更稳 |
| s4-ring | 蜂房环 | 粗环 + 强调核，几何感最强 |
| s5-triple | 三层嵌套 | 三个同心层级，纵深感更强 |
| s6-no-core | 去核轮廓 | 仅留双层轮廓，最克制 |
| s7-hex-core | 六边形核 | 中心核换成小六边形，与外轮廓同族 |
| s8-cluster | 蜂窝簇 | 中心 + 六邻，直接画出蜂巢结构 |
| s9-fine | 细线版 | 线宽减三成，小尺寸与浅底更清爽 |
| s10-bold | 粗线版 | 线宽加四成，大尺寸与深底更厚重 |

## 使用说明

- 所有 PNG 均为 RGBA，四角完全透明，可直接叠在任何底色上。
- SVG 文件里没有 `<rect>` 背景，浏览器与设计软件中天然透明；字形已转曲为路径，不依赖系统字体。
- `atom-icon-reverse-*` 是深底专用版：主线换成 #F2F0EC，强调色保持原值。
- 图标画布为 100×100 viewBox，图形按实际墨迹居中并留 6 单位安全边距。
- 锁定组合版固定 viewBox `0 0 271.21 134.78`，导出宽度 1400px。
