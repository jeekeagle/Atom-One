03 · ABOUT

Atom-One 是什么

名字来自 Atom 方法体系的核心：把智能体拆解到不可再分的最小单元，再看单元如何组合成系统。

WHY ATOM

原子式拆解

外层六边是边界容器，内层六边是可拆解单元，中心实心点是不可再分的核。任何复杂系统，都可以拆到这一层再来理解。

WHY ONE-PAGE

单页形态

一篇文章一个文件，CSS/JS 全内联、零外链。不翻页、不依赖服务器，拷走就能看，半年后打开也不会坏。

HOW IT GROWS

靠清单生长

新页面只需两步：把 HTML 放进目录，在 pages.json 里加一条。首页自动收录，无需改代码。

04 · CONTRIBUTE

再加一篇单页要几步

给自己和 AI 的备忘录：目录位置、登记格式、视觉约定。

  1. 把写好的单页 HTML 放进对应子目录：skills/ 放 skill 文档，pages/ 放一般主题。
  2. 在仓库根目录的 pages.json 里追加一条记录：标题、简介、相对路径、分类、标签、日期。
  3. 刷新首页即可看到 —— 卡片、搜索、分类筛选全部自动生效。
  4. 页面沿用同一套视觉：白纸面、墨黑正文、赭红锚点色，字体走系统中文字体栈，不引外链。
// pages.json —— 追加一条 { "title": "页面标题", "desc": "一句话说明这篇单页讲什么", "url": "skills/xxx.html", "cat": "skill", // skill | asset "tags": ["标签一", "标签二"], "date": "2026-10-28" }
清单加载不了也能正常显示。首页内嵌了一份同样的清单作为兜底： 直接用 file:// 打开、或 pages.json 尚未提交时， 依然能看到已登记的单页。
